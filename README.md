# 🗡️ TextConsoleRPG : 순정 콘솔의 한계 돌파

> **내일배움캠프 C++ 심화 과제** : 상용 게임 엔진 없이 C++ 표준 라이브러리와 Windows API만을 사용하여 구현한 턴제 텍스트 RPG 프로젝트입니다. 단순한 텍스트 출력을 넘어, 콘솔 창 내부에서 작동하는 **자체 픽셀 렌더링 엔진**과 **데이터 주도 설계(Data-Driven Design)**를 구축하여 콘솔의 한계를 극복했습니다.

<br>

## 📖 게임 개요
플레이어는 용병을 고용해 파티를 구성하고, 장비를 세팅하여 마왕 둠브링어를 토벌하기 위한 여정을 떠납니다. 마을, 주점, 대장간, 던전 등 다양한 장소를 탐험하며 파티를 성장시킬 수 있습니다.

* **개발 언어:** C++17 (MSVC)
* **개발 환경:** Visual Studio / Windows Console
* **핵심 키워드:** `OOP`, `FSM`, `Data-Driven`, `Double-Buffering Rendering`, `AI`

## 🛠️ 핵심 아키텍처 및 개발 일지 (TIL)

이 프로젝트는 5가지 핵심 프로그래밍 개념을 바탕으로 설계되었습니다. 각 기능의 도입 배경과 구현 방식에 대한 상세한 기록입니다.

### 1. FSM 기반의 안전한 씬(Scene) 전환
* **Why:** 게임 내의 다양한 장소(마을, 던전, 상점)가 엉키지 않고 플레이어의 조작에 따라 깔끔하게 전환되는 구조가 필요했습니다.
* **How:** `enum class EGameState`를 이용해 상태를 정의하고, 게임의 메인 `while` 루프 안에서 `switch` 문으로 현재 상태에 맞는 함수만 실행되도록 **유한 상태 머신(FSM)**을 구축했습니다.
* **Result:** 장소가 바뀔 때마다 무대 세트를 교체하듯 화면과 로직이 안전하게 전환되며, 새로운 장소를 추가할 때 기존 코드를 수정할 필요가 없는 유연성을 확보했습니다.

### 2. 붕어빵 틀과 유전자 (객체 지향 프로그래밍, OOP)
* **Why:** 전사, 마법사, 사제 등 수많은 직업과 다양한 몬스터들의 체력, 공격 로직을 개별 변수로 하드코딩하면 유지보수가 불가능해집니다.
* **How:** `ACharacter`라는 최상위 부모 클래스(설계도)를 만들고, 모든 공통 스탯과 가상 함수(`virtual`)를 정의했습니다. `AMage`, `AWarrior` 등은 이 유전자를 **상속(Inheritance)** 받아 자신만의 고유한 스킬과 공격 방식(`override`)을 구현합니다.
* **Result:** `new AMage()` 명령어 한 줄로 완벽히 작동하는 마법사 객체를 생성할 수 있으며, 클래스 간의 결합도를 낮추어 확장이 매우 쉬워졌습니다.

### 3. 요리사와 레시피의 분리 (데이터 주도 설계, Data-Driven)
* **Why:** 새로운 물약이나 장비를 추가할 때마다 상점 시스템의 핵심 로직 코드를 매번 열어서 수정하고 재컴파일하는 비효율을 막아야 했습니다.
* **How:** 시스템(요리사)과 데이터(레시피)를 분리했습니다. `GameDatabase.h/cpp` 라는 독립된 데이터 저장소를 구축하여 모든 아이템, 몬스터, 용병의 정보를 배열(`std::vector`)로 보관합니다.
* **Result:** 새로운 보스 몬스터나 전설 등급 아이템을 추가할 때 시스템 코드는 단 한 줄도 건드리지 않고, 오직 데이터베이스에 텍스트 한 줄만 추가하면 게임 전체에 자동 적용됩니다.

### 4. 도화지 겹쳐 그리기 (자체 픽셀 렌더링 엔진)
* **Why:** 콘솔 창에서 텍스트를 위에서 아래로 계속 찍어내면 화면이 심하게 깜빡이고 찢어지는 현상(Tearing)이 발생하여 시각적인 몰입을 방해했습니다.
* **How:** 슈퍼 마리오 등에서 쓰이던 **더블 버퍼링(Double Buffering)**과 레이어 합성 기법을 도입했습니다. 
  1. `배경`, `몬스터`, `이펙트` 라는 3개의 투명 캔버스(2차원 배열)를 생성.
  2. 트루 컬러(RGB) ANSI 이스케이프 코드와 공백 2칸(`  `)을 조합해 완벽한 정사각형 픽셀을 생성.
  3. 3장의 레이어를 압축 연산하여 하나의 거대 `std::string` 버퍼에 담은 뒤, 화면에 단 1회만 출력 (`RenderViewport`).
* **Result:** 콘솔 창이라고는 믿기지 않는 부드러운 60프레임급 프레임 애니메이션(베기 이펙트, 스킬 셰이더)과 깜빡임 없는 풀컬러 픽셀 아트를 구현해 냈습니다.

### 5. 확률 기반 전술 전투 (Combat AI)
* **Why:** 적이나 아군이 체력이 없는데도 무의미한 공격만 반복하는 수동적인 전투를 탈피하고자 했습니다.
* **How:** C++ `<random>` 라이브러리를 활용해 난수(주사위)를 생성하고, **상황 인지(Situational Awareness)** 로직을 더했습니다. 
  * 1순위 (생존): HP가 50% 이하일 때 일정 확률로 인벤토리의 포션을 스캔하여 복용.
  * 2순위 (전술): MP가 충분할 때 직업 특성에 맞는 스킬 사용 (사제는 HP가 가장 낮은 아군을 찾아 힐을 시전).
  * 3순위 (기본): 모든 조건이 안 맞거나 스킬에 실패하면 기본 공격 수행.
* **Result:** `if-else` 분기와 확률 가중치를 조합하여, 상황에 맞게 물약을 먹고 아군을 구출하는 똑똑한 전투 AI를 완성했습니다.
